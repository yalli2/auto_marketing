# auto_marketing — 다인에듀 AI 마케팅 자동화

AI 에이전트가 **잠재고객을 찾고**, 홈페이지에서 **수신동의와 함께 이메일을 받고**, **승인된 홍보 메일을 자동 발송**하는 시스템입니다.

> 처음 설치는 [SETUP.md](SETUP.md), 법규 점검표는 [COMPLIANCE.md](COMPLIANCE.md)를 보세요.

## 먼저 알아둘 것: "이메일을 긁어서 보내는" 방식은 쓰지 않습니다

- 남의 홈페이지에서 프로그램으로 이메일 주소를 모으는 것은 정보통신망법 제50조의2가 금지합니다(형사처벌 대상).
- 수신동의 없이 광고 메일을 보내는 것은 같은 법 제50조 위반입니다(과태료 대상, 2026년 개정으로 과징금 추가).
- 동의를 받으려고 보내는 첫 메일도 동의 없는 광고로 취급됩니다.

그래서 이 시스템은 **"찾아가서 보내기"가 아니라 "찾아서 데려오고, 동의받고, 보내기"** 구조입니다.

## 전체 흐름

```
 ┌─────────────────────────┐      ┌──────────────────────────┐
 │ 에이전트 1 (매주 월)      │      │ 에이전트 2 (매주 목)        │
 │ 잠재고객 발굴             │      │ 뉴스레터 + 유입용 글 작성    │
 │ · 입찰/모집 공고          │      │ · newsletters/날짜.html    │
 │ · 중남미 진출 기업        │      │ · content/날짜/blog, sns   │
 │ → 구글 드라이브 리포트     │      │ → 이 저장소에 커밋          │
 └───────────┬─────────────┘      └────────────┬─────────────┘
             │ 원장님이 공식 창구로 제안           │ 블로그·SNS 게시 → 방문자 유입
             ▼                                  ▼
      기관이 자료 요청 ──────────►  구독 신청 페이지 (index.html)
                                   수신동의 체크 + 확인 메일(더블 옵트인)
                                              │
                                              ▼
                              구글 시트 Subscribers (비공개 보관)
                                              │
            매일 08시: queue.json 확인 → 원장님께 미리보기 메일
                                              │  [발송 승인] 클릭
                                              ▼
                    09~18시 자동 발송: (광고) 표기 · 전송자 정보 · 수신거부 링크
```

## 다른 AI 툴이 필요한가?

필요 없습니다. 역할은 이렇게 나뉩니다.

| 일 | 담당 | 비용 |
|---|---|---|
| 잠재고객 조사, 제안문 초안, 뉴스레터·블로그·SNS 글 작성 | Claude 예약 작업 (웹 검색, GitHub, 구글 드라이브 연결) | 기존 Claude 구독 |
| 구독 신청 페이지 | GitHub Pages (이 저장소) | 무료 |
| 구독자 명단, 동의 기록, 메일 발송, 수신거부 처리 | Google Apps Script + 구글 시트 + Gmail | 무료 |

Claude가 직접 하지 않는 것은 **구독자에게 메일을 실제로 내보내는 일** 하나입니다. 이것은 Apps Script가 원장님 계정으로, 원장님 승인 후에 합니다.
구독자가 하루 80명 발송 한도(무료 Gmail 기준)를 넘어서면 스티비 같은 이메일 발송 서비스로 옮기는 것을 권합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html`, `config.js` | 구독 신청 페이지 (GitHub Pages로 공개) |
| `apps_script/Code.gs` | 구독·수신거부·승인·발송 백엔드 |
| `agents/01_prospect_discovery.md` | 잠재고객 발굴 에이전트 지침 |
| `agents/02_weekly_content.md` | 주간 콘텐츠 에이전트 지침 |
| `config/targets.md` | 누구를 찾을지 (세그먼트, 검색어) |
| `config/offers.md` | 무엇을 홍보할 수 있는지 (사실 목록) |
| `newsletters/` | 발송 대기열(`queue.json`)과 뉴스레터 본문 |
| `content/` | 블로그·SNS용 글 (에이전트 2가 매주 추가) |

## 이 저장소는 공개입니다

구독자 이메일, 잠재고객 리포트 같은 자료는 **절대 이 저장소에 올리지 않습니다.**
구독자 명단은 구글 시트에, 리포트는 구글 드라이브에만 저장됩니다.

## 매주 원장님이 하는 일 (약 15분)

1. 월요일: 드라이브의 `잠재고객 리포트`를 열어 상위 3곳에 공식 창구로 제안 (초안이 들어 있음)
2. 목요일~월요일: `content/날짜/` 의 블로그·SNS 글을 채널에 게시
3. 화요일 아침: 미리보기 메일을 읽고 `[발송 승인]` 클릭

## 성과 확인

- 구글 시트 `Subscribers`: 구독자 수, 유입 경로(`source`), 수신거부 수
- 구글 시트 `SendLog`: 발송 기록
